# Iteration 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the top-bar and toolbar polish, subject glyphs, chip filters with a Drill setup card, the two-panel Mock setup, an editor colour theme preference, and five new subjects with 40 translated questions.

**Architecture:** Small pure modules (`glyphs.ts`, `filterFacets.ts`, `editorThemes.ts`) feed presentational components (`Glyph`, `ChipGroup`, `OnlyChips`, `Stepper`) that the pages compose. Content tasks are pure data files validated by the existing content test.

**Spec:** `docs/superpowers/specs/2026-09-23-iteration-3-design.md` (binding).

## Global Constraints

TypeScript strict, explicit return types, labeled import groups (`// packages`, `// components`, `// content`, `// engine`, `// hooks`, `// utils`, `// i18n`), no barrel files, no commented-out code, no eslint-disable, exact pins, npm only. Commit subjects start with a capitalized verb from the commit-msg allowlist (Add, Fix, Update, Create, Remove, Improve, Refactor, Move, Rename, Configure, Enable, Extract, Simplify, Implement, Replace, Support, Use, Set, Reduce, Test, Seed, Wire…) and have no trailing period; every commit ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Never push. Never touch `.superpowers/`. Branch `feature/academy-v1`. Every task ends with `npm run lint && npx vitest run && npm run build` green (3 pre-existing react-refresh warnings are fine). All new user-facing strings go through i18next with keys in both `en.json` and `es.json` (the parity test enforces it). Icons only from `react-icons/{si,fi,tb}`.
